# 通用 Mini-Lang 翻譯範例

> 一般中文翻成[通用 Mini-Lang](universal.md)，以及 Mini-Lang 翻回一般中文的範例。字表是第 3 版的 297 字，數字用阿拉伯數字。
> 所有文章都是為本文件新寫的。Mini-Lang 版由人依規則翻譯；「自動反譯」是 [translate.py](translate.py) `--to-zh` 的結果，只查詞典、不改句子結構。

## 結論

* **8 段文章都翻得過去。** 包括日常、新聞、科普、議論、寓言、說明、書信與故事，每一段都只用 297 字、阿拉伯數字和少數英文外來語。
* **意思都保留了。** 時間、數量、因果、對比、說話者的看法都在；失去的是文體（全部變成口語）與一些細微差別（雨「聲」、「笑」）。
* **詞典讓大部分的詞能自動翻回來。** 地鐵、市長、機場、居民、傍晚、夕陽、規則、準備、炒、爬山都能還原。
* **人工翻譯仍然比自動反譯好。** 自動反譯不會改量詞、語氣與句子結構，也可能把描述的一部分誤認成別的詞（第 3 節）。

## 一、中文 → Mini-Lang

### 範例 1：日常：週末的早上

原文：

```text
星期六早上，我很早就起床了。我到廚房煮了兩顆雞蛋，烤了一片麵包，又泡了一杯咖啡。吃早餐的時候，窗外開始下雨，雨聲很大。我一邊吃，一邊看新聞。新聞說，這場雨會一直下到星期一。我想，今天大概不能出去散步了，只好在家裡看書。
```

Mini-Lang：

```zh
週6早上，我很早就起來了。我到做飯的房間，拿2個蛋放在熱水裡做，在火上做了一個 bread（西方人早上愛吃的、用火做出來的吃的東西），再做了一個 coffee（黑色的、喝了就不想睡覺的熱的東西）。吃早飯的時候，外邊下起雨來了，雨聲很大。我一邊吃，一邊看最近的大事。上邊說，這個雨會從今天下到週1。我想，今天可能不能出去走走了，只好在家裡看書。
```

自動反譯：

```text
週6早上，我很早就起來了。我到廚房，拿2個蛋煮，烤了一個麵包，再做了一個咖啡。吃早飯的時候，外邊下起雨來了，雨聲很大。我一邊吃，一邊看新聞。上邊說，這個雨會從今天下到週1。我想，今天可能不能出去走走了，只好在家裡看書。
```

翻譯重點：

* 「星期六」→「週6」，「起床」→「起來」：字表外的詞先找字表內的同義詞。
* 「煮、烤、泡」都用「做」加上方法：「放在熱水裡做」「在火上做」；「雞蛋」直接寫「蛋」。
* 「雨聲很大」：第 3 版加入「聲」以後，可以直接寫。
* 「一顆、一片、一杯」都改成「一個」（只用六個量詞）。

### 範例 2：新聞：新的地鐵

原文：

```text
本市第三條地鐵線昨天正式通車。這條路線全長二十五公里，共有十八個車站，從市中心通往機場。市長在典禮上表示，新路線每天可以載送大約十萬名乘客，並減少路上的汽車和空氣污染。不過，也有居民擔心票價太高。
```

Mini-Lang：

```zh
昨天，這個城的第3個地下走的電車開了。這個電車要走 25 km，有18個車站，從城的中間到坐飛機的地方。做地方大事的頭在那天的大事上說，新的電車每天可以給10萬個左右的人坐，路上的車會少一點，不好的氣也會少一點。可是，也有住在這裡的人覺得 ticket（坐車、坐飛機以前要買的、上邊有字的小東西）會太貴。
```

自動反譯：

```text
昨天，這個城的第3個地鐵開了。這個電車要走 25 km，有18個車站，從城的中間到機場。市長在那天的大事上說，新的電車每天可以給10萬個左右的人坐，路上的車會少一點，空氣污染也會少一點。可是，也有居民覺得票會太貴。
```

翻譯重點：

* 「城」在字表內，「本市」說成「這個城」；「市」不在，「市長」用詞典的「做地方大事的頭」。
* 「載送十萬名乘客」改寫成「可以給10萬個左右的人坐」：數字用阿拉伯數字，「大約」用「左右」。
* 「空氣污染」用詞典的「不好的氣」；「擔心票價太高」改成「覺得 ticket 會太貴」。
* 「25 km」：單位用國際符號，不需要說明。

### 範例 3：科普：天為什麼是藍的

原文：

```text
太陽光看起來是白色的，其實是由很多種顏色的光混合而成。光進入大氣層以後，會碰到空氣中很小的分子。藍色的光比紅色的光更容易被這些分子散射到四面八方，所以我們抬頭看天空時，到處都看得到藍光。到了傍晚，陽光要穿過更厚的空氣才能到達我們的眼睛，藍光在路上被散射掉了，剩下的多半是紅色和橙色的光，所以夕陽是紅的。
```

Mini-Lang：

```zh
日頭的光看起來是白色的，說真的，那是很多色的光在一起。光走進天空的空氣裡以後，會打到空氣裡很小很小的分子。藍色的光和紅色的光比，更多給這些分子打到每一邊去，所以我們看天空的時候，哪裡都看得到藍色的光。到了天快黑的時候，日頭的光要走過更多的空氣，到我們的眼裡。藍色的光在路上都給打走了，還沒用完的多半是紅色的光，和紅色和金色中間的色的光，所以快下山的日頭是紅的。
```

自動反譯：

```text
日頭的光看起來是白色的，說真的，那是很多色的光在一起。光走進天空的空氣裡以後，會打到空氣裡很小很小的分子。藍色的光和紅色的光比，更多給這些分子打到每一邊去，所以我們看天空的時候，到處看得到藍色的光。到了傍晚，日頭的光要走過更多的空氣，到我們的眼裡。藍色的光在路上都給打走了，剩下的多半是紅色的光，和橘色的光，所以夕陽是紅的。
```

翻譯重點：

* 「藍色、天空、空氣、光」：第 3 版加入「藍、空、光」以後，都可以直接寫（第 2 版要說「天上的色的 light」，讀起來很繞）。
* 「散射」沒有簡單的說法，改寫成動作：「給這些分子打到每一邊去」。
* 「橙色」用紅、金兩色組合：「紅色和金色中間的色」。
* 「才能到達」字表沒有「才」，拆成兩句。

### 範例 4：議論：孩子與手機

原文：

```text
現在很多孩子從小就有自己的手機。手機讓他們能隨時和家人聯絡，也能很快查到資料。但是，如果孩子每天花太多時間玩手機，就會少了運動和跟朋友見面的機會，睡眠也可能受到影響。我認為，問題不在於手機本身，而在於使用的方法。父母應該和孩子一起訂出規則，例如吃飯和睡覺前不用手機。
```

Mini-Lang：

```zh
現在很多孩子很小就有自己的手機。手機叫他們什麼時候都能和家人說話，也能很快找到想看的東西。可是，要是孩子每天用太多時間玩手機，和朋友見見、做 sport（叫身體好起來的事，比方說很快地走）的時候就少了，睡覺也可能睡不好。我覺得，問題不是手機，是怎麼用手機。爸媽要和孩子一起想出大家說好要這樣做的事，比方說吃飯和睡覺以前不用手機。
```

自動反譯：

```text
現在很多孩子很小就有自己的手機。手機叫他們什麼時候都能和家人說話，也能很快找到想看的東西。可是，要是孩子每天用太多時間玩手機，和朋友見見、做運動的時候就少了，睡覺也可能睡不好。我覺得，問題不是手機，是怎麼用手機。爸媽要和孩子一起想出規則，比方說吃飯和睡覺以前不用手機。
```

翻譯重點：

* 「讓他們能隨時聯絡」→「叫他們什麼時候都能說話」：使役用「叫」，「隨時」用「什麼時候都」。
* 「問題不在於手機本身，而在於使用的方法」改成很短的對比句：「問題不是手機，是怎麼用手機」。
* 「訂出規則」→「想出大家說好要這樣做的事」，詞典能還原成「規則」。

### 範例 5：寓言：兩個 ant

原文：

```text
夏天的時候，一隻螞蟻每天忙著把食物搬回家，另一隻螞蟻卻整天在樹下唱歌。忙碌的螞蟻說：「冬天快到了，你也應該準備一些食物。」唱歌的螞蟻笑著說：「現在天氣這麼好，急什麼？」冬天來了，地上都是雪，唱歌的螞蟻又冷又餓，只好去敲朋友的門。朋友打開門，讓牠進來，分給牠一半的食物，說：「明年夏天，我們一起工作吧。」
```

Mini-Lang：

```zh
熱天的時候，有一個 ant（很小很小、很多很多一起住在地下的蟲）每天都很忙，拿吃的東西回家；還有一個 ant 從早到晚都在樹下唱歌。很忙的那個 ant 說：「冷天快到了，你也要先做好一些吃的東西。」唱歌的那個 ant 笑了，說：「現在天氣這麼好，你忙什麼？」冷天來了，地上都是雪。唱歌的那個 ant 很冷，也很想吃東西，只好去叫朋友的門。朋友打開門，叫他進來，給了他一半吃的東西，說：「明年熱天，我們一起工作吧。」
```

自動反譯：

```text
熱天的時候，有一個螞蟻每天都很忙，拿食物回家；還有一個螞蟻整天都在樹下唱歌。很忙的那個螞蟻說：「冷天快到了，你也要準備一些食物。」唱歌的那個螞蟻笑了，說：「現在天氣這麼好，你忙什麼？」冷天來了，地上都是雪。唱歌的那個螞蟻很冷，也很餓，只好去叫朋友的門。朋友打開門，叫他進來，給了他一半食物，說：「明年熱天，我們一起工作吧。」
```

翻譯重點：

* 「夏天、冬天」用「熱天、冷天」，這是中文本來就有的詞。
* 「笑著說」字表沒有「著」，說成「笑了，說」；「急什麼」改成「你忙什麼」；「唱歌、樹、雪」都在字表內。
* 「另一隻螞蟻」字表沒有「另」，說成「還有一個 ant」。
* 「敲門」用詞典的「叫門」。

### 範例 6：說明：蛋飯怎麼做

原文：

```text
蛋炒飯是很簡單的家常菜。先把兩顆蛋打散，倒進熱油裡炒熟，盛起來備用。接著放入一碗冷飯，用中火炒三分鐘，再加入蛋、蔥花和一點鹽，炒勻就可以吃了。用前一天剩下的飯來炒，味道最好。
```

Mini-Lang：

```zh
蛋飯是家裡天天做、做起來不難的菜。先拿2個蛋打開，打一打，放進熱 oil（做菜時先放下去的東西，在手上很難洗）裡，用火很快地做好，拿出來放在一邊。再放進一些冷飯，火不大不小，用火很快地做3分鐘，再放進蛋、一點 scallion（做菜時放一點的、長長的小菜）和一點 salt（做菜時要放一點的白色小東西，放多了菜就很難吃），做到每個地方都一樣了，就可以吃了。用前一天沒吃完的飯來做，味道最好。
```

自動反譯：

```text
蛋飯是家裡天天做、做起來不難的菜。先拿2個蛋打開，打一打，放進熱油裡，炒好，拿出來放在一邊。再放進一些冷飯，火不大不小，炒3分鐘，再放進蛋、一點蔥和一點鹽，做到每個地方都一樣了，就可以吃了。用前一天沒吃完的飯來做，味道最好。
```

翻譯重點：

* 「炒」用詞典的「用火很快地做」，反譯能還原成「炒」。
* 「中火」說成「火不大不小」，「炒勻」說成「做到每個地方都一樣」。
* 「味道最好」：第 3 版加入「味」以後，可以直接寫。
* 這一段外來語最多（oil、scallion、salt），因為食材很難只用描述分清楚；「蛋」在第 3 版改回中文。

## 二、Mini-Lang → 中文

先用 Mini-Lang 寫，再翻成一般的書面中文。

### 範例 7：給媽媽的信

Mini-Lang 原文：

```zh
媽媽：

你好嗎？我在這裡很好。這裡的人都很好心，我的老師也很會教。天氣一天比一天冷了，我買了一個大衣。我每天都好好吃飯、早點睡覺，你不用不放心。下個月我就回家了，到時候我們一起走上山吧。

你的孩子
```

人工翻譯：

```text
媽媽：

您好嗎？我在這裡一切都好。這裡的人都很善良，老師也很會教。天氣越來越冷了，我買了一件大衣。我每天都按時吃飯、早點睡覺，請您放心。下個月我就回家了，到時候我們一起去爬山吧。

您的孩子
```

自動反譯（比較用）：

```text
媽媽：

你好嗎？我在這裡很好。這裡的人都很好心，我的老師也很會教。天氣越來越冷了，我買了一個大衣。我每天都好好吃飯、早點睡覺，你不用不放心。下個月我就回家了，到時候我們一起爬山吧。

你的孩子
```

人工翻譯：

```text
媽媽：

您好嗎？我在這裡一切都好。這裡的人都很善良，老師也很會教。天氣越來越冷了，我買了一件大衣。我每天都按時吃飯、早點睡覺，請您放心。下個月我就回家了，到時候我們一起去爬山吧。

您的孩子
```

翻譯重點：

* 「你好嗎、你不用不放心」翻成書面中文時，改成「您好嗎、請您放心」，語氣更正式。
* 「一天比一天冷」→「越來越冷」，「走上山」→「爬山」，「好心」→「善良」：這些都能用詞典還原。
* 「一個大衣」改回正確的量詞「一件大衣」。

### 範例 8：找 dog

Mini-Lang 原文：

```zh
我家的 dog（會看家、會叫的小東西）不見了。我和爸爸在路上找了很長時間，問了很多人，大家都說沒看見。天快黑的時候，有一個小孩很快地走過來，說：「你們在找的是不是一個白色的 dog？他在學校門口。」我們到了學校門口，真的看見了我家的 dog。他一看見我，就很快地走過來，我們都很開心。我對那個孩子說了很多次謝謝。
```

人工翻譯：

```text
我家的狗走丟了。我和爸爸在街上找了很久，問了很多人，大家都說沒看到。傍晚的時候，一個小孩跑過來說：「你們在找的是不是一隻白色的狗？牠在學校門口。」我們趕到學校門口，果然看到了我家的狗。牠一看到我，就跑了過來，我們都很高興。我向那個孩子道謝了好幾次。
```

自動反譯（比較用）：

```text
我家的狗丟。我和爸爸在路上找了很長時間，問了很多人，大家都說沒看見。傍晚，有一個小孩跑過來，說：「你們在找的是不是一個白色的狗？他在學校門口。」我們到了學校門口，真的看見了我家的狗。他一看見我，就跑過來，我們都愉快。我對那個孩子說了很多次謝謝。
```

人工翻譯：

```text
我家的狗走丟了。我和爸爸在街上找了很久，問了很多人，大家都說沒看到。傍晚的時候，一個小孩跑過來說：「你們在找的是不是一隻白色的狗？牠在學校門口。」我們趕到學校門口，果然看到了我家的狗。牠一看到我，就跑了過來，我們都很高興。我向那個孩子道謝了好幾次。
```

翻譯重點：

* 「不見了」翻成「走丟了」，「很長時間」翻成「很久」，「很快地走過來」翻成「跑過來」。

| 1 日常：週末的早上 | 94 | 133 | 1.4 | bread、coffee |
| 2 新聞：新的地鐵 | 89 | 119 | 1.3 | ticket |

| 4 議論：孩子與手機 | 121 | 142 | 1.2 | sport |

### 自動反譯會出的錯

翻譯這些範例時，`translate.py` 出過下面幾種錯。範例中的 Mini-Lang 已經換了說法來避開，但這些是工具本身的限制：

| 錯誤 | 反譯的情形 | 原因 |
|---|---|---|
| 描述的一部分被誤認成別的詞 | 「這個電車走的路」→「這個電路線」 | 「車走的路」是「路線」的描述，正好出現在句子裡 |
| 短的動作描述被換掉 | 「放在一起」→「加」、「要知道的東西」→「要知識」 | 詞典的描述也是很常見的說法 |
| 同一個英文詞對應兩個中文詞 | 「orange」→ 橘子還是橘色？ | 外來語本身有歧義；詞典只取第一個 |
| 語氣與量詞不會改回來 | 「一個大衣」、「我們都愉快」 | 反譯只換詞，不改句子 |

要做得更好，反譯需要能看懂上下文的模型，而不只是查詞典。這正好是一個適合交給語言模型的工作：把 Mini-Lang 改寫成通順的書面中文。
